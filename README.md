# Inscrição na Semana de Tecnologia

Aplicação acadêmica em React + Vite para gerenciar inscrições em oficinas de uma semana de tecnologia.

## Funcionalidades
- Formulário com nome, e-mail e oficina.
- Validação de campos e prevenção de e-mails duplicados.
- Listagem dinâmica de participantes.
- Remoção de inscrições e contador de participantes.
- Interface responsiva.

## Executar localmente
Requisitos: Node.js 20+ e npm.

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
